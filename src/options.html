GIPHY API Key

By default, GIFs for GitHub uses KLIPY as its GIF provider. If you have your own GIPHY API key, you can use GIPHY instead.

This is an advanced option. You can get a GIPHY API key from developers.giphy.com. Note that GIPHY may charge for API usage depending on your usage level.

Slash Command

Type /gif at the start of a line in any comment box to search for and insert a GIF inline. Add a search term like /gif cats to search directly.

GIF Size

Width (in pixels) applied to inserted GIFs. Leave empty to use the GIF's original size.
